# Inertia React frontend rules

- This is Inertia, not Next: no `useEffect`+fetch for page data — it arrives as props from
  the controller. Navigation is `Link`/`router` from `@inertiajs/react`; forms are Inertia
  `<Form>`/`useForm`, never react-hook-form or zod resolvers.
- Props are typed with the Typelizer output in `types/generated` (regenerated by
  `bin/check`, never edited by hand).
- Tailwind v4 is loaded **without preflight** (`stylesheets/application.css`): the landing in
  `landing.css` depends on the browser defaults. Do not add `@import "tailwindcss"`.
- `landing/scene.ts` is the verbatim three.js game from the prototype, under `@ts-nocheck`.
  Change its `DEFAULTS` to tune the flight; keep it diffable against the original rather
  than restyling it. Typing it is a separate task.
- New page directories under `pages/` need the Vite dev server restarted (touch
  `vite.config.ts`), or every page 504s with "Outdated Optimize Dep".
