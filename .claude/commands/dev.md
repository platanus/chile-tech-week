Start this checkout's dev stack with `OVERMIND_DAEMONIZE=1 bin/dev` (Rails + Vite under Overmind; the main checkout serves http://localhost:3000, a worktree prints its own ports). If `overmind status` says it is already running, leave it. Then confirm `curl -s localhost:$PORT/up` answers 200 and report the URL.
